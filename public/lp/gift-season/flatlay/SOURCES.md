# Gift a Season hero A flat lay: sources

Every file is a cutout of live Shopify product photography. The white background and the baked-in shadow were removed with background matting (rembg isnet-general-use; u2net for the polo). The hat already had a transparent background, so only its dark shadow pixels were removed. Each piece was then trimmed and resized to 1000px max (the polo to 800px). Nothing else about the products was generated or edited. The page adds one shared CSS drop shadow to all four.
